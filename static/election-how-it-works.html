Confluence Scoring

A single strategy firing is interesting. Multiple strategies pointing the same direction on the same market is actionable. The system stacks confirming signals automatically:

// Group signals by (market_id, side)
lead_signal = highest_confidence in group
boost = min(24, confirming_sources × 8)
final_confidence = min(85, lead + boost)

// Kelly gets a multiplier too:
agreement_mult = 1.0 + (0.10 × extra_sources)
// 2 sources = 1.1x, 3 = 1.2x, 4 = 1.3x Kelly

Confidence & Kelly Sizing

Each signal's raw confidence passes through Bayesian adjustment — the system tracks how often each strategy's trades actually win. Sources that perform well get boosted; poor performers get dampened.

The Kelly Criterion then converts confidence into bet size:

// Kelly formula with variable odds
b = (1 - market_price) / market_price
p = adjusted_confidence / 100
kelly_raw = (b × p - (1 - p)) / b

// If kelly_raw ≤ 0, there is no mathematical edge
// Only trade when kelly_raw > 0

bet_size = bankroll × kelly_raw × (1/6) × agreement_mult

Key insight: A signal with 60% confidence on a market priced at 55% has a tiny edge. The same 60% confidence on a market priced at 30% has a large edge. Kelly naturally sizes bigger when the odds are in our favor.

Additionally, a Market Gate blocks trades where signal confidence diverges more than 20% from the market price — preventing us from stubbornly betting against strong market consensus.
