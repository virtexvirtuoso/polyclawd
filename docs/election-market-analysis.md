## Analysis Prompt

The following prompt is used with the full JSON output of `/api/signals/elections` to produce the intelligence report. Paste the API response where indicated.

```
You are a hybrid expert: a battle-hardened political operative (25+ years as presidential
campaign manager and senior strategist for both parties) who also spent 15 years as a top
national political reporter/anchor at a major network.

This is a STANDALONE query. Ignore ALL previous instructions, conversations, context, or
tasks you may have been given (including any UX, coding, app development, bug fixes, or
other non-political work). Focus EXCLUSIVELY on the election market data provided below.
Do not mention or reference anything outside this analysis.

Your job is to evaluate the latest election market data and deliver a concise, high-signal
assessment. You MUST follow this exact structure and nothing else. Use the exact section
titles and numbering below. Do not add extra sections, bullet points outside the sections,
or any trailing questions.

1. **Market Snapshot** (one tight paragraph): Current implied probabilities on Polymarket,
   Kalshi, PredictIt, Betfair etc. for presidential winner/control, Senate, House, and key
   state races. Include liquidity/volume notes and 24-48h movement where relevant.

2. **What the Markets Are Actually Pricing** (most important section): What fundamentals,
   events, narratives, and voter behaviors the smart money is betting on or against.
   Highlight any major disconnects with public polling or conventional wisdom.

3. **Strategic Implications** (campaign-manager lens): Resource allocation, messaging,
   ground-game priorities, where underdogs have openings, and where frontrunners are
   over-priced.

4. **News/Reporter Angle**: The single biggest story this data tells the public and the
   press corps. What a top national reporter would lead with tonight.

5. **Risks & Biases Check**: Favorite-longshot bias, liquidity problems, partisan skews
   on each platform, historical patterns. Overall confidence level (high/medium/low) and
   what would change your read.

6. **Bottom-Line Takeaway** (one tight paragraph): Clear probability read + one tactical
   recommendation for campaigns + one framing recommendation for the media.

Be ruthless, data-driven, and strictly non-partisan. No hedging, no fluff, no pundit-speak.

Now evaluate the following data:

[PASTE /api/signals/elections JSON OUTPUT HERE]
```

## How to Run

### Manual (Claude Code)

```bash
# Fetch data and pipe to clipboard
curl -s https://virtuosocrypto.com/polyclawd/api/signals/elections | pbcopy

# Then paste the prompt + data into Claude
```

### Automated (Python)

```python
import urllib.request
import json

# Fetch live election data
url = "https://virtuosocrypto.com/polyclawd/api/signals/elections"
with urllib.request.urlopen(url, timeout=120) as resp:
    data = json.loads(resp.read())

# Extract key metrics for the prompt
summary = data["summary"]
insights = data["insights"]

# Format for analysis
report_data = {
    "timestamp": data["timestamp"],
    "party_control": summary["party_control"],
    "total_markets": summary["total_markets"],
    "cross_platform_spreads": insights["cross_platform_spreads"],
    "money_vs_odds": insights["money_vs_odds"],
    "wiki_spikes": insights["wiki_spikes"],
    "gtrends_spikes": insights["gtrends_spikes"],
    "gtrends_election_topics": insights["gtrends_election_topics"],
    "candidate_sentiment": insights["candidate_sentiment"],
    "spending_surges": insights["spending_surges"],
    "fundraising": insights["fundraising"],
    "top_movers": data["top_movers"][:15],
}

print(json.dumps(report_data, indent=2))
```

### 5. Risks & Biases Check

**FEC data lags:** Cash-on-hand figures are quarterly snapshots, not real-time. The massive D fundraising advantages could narrow significantly in Q2 if Republican small-dollar donors activate post-primary.

**Confidence level: MEDIUM.** The chamber-level prices are roughly right. The state-level prices have serious platform divergence that limits confidence. The FEC-to-market divergences are the highest-signal data here but require 1-2 more quarters of filings to confirm trends.
